# ElectricTools · 电路学习工具

画电路 → 自动求解 → 给公式/数值/波形/手算步骤。面向《电工与电子技术》教学。

## 目录

| 目录 | 作用 |
|---|---|
| `frontend/` | 画布前端（原生 ES 模块 + Vite，无框架） |
| `solver/app/` | 求解后端（FastAPI + WebSocket + lcapy 符号引擎） |
| `storage/circuits/` | 电路存档（`canvas.json` + 会话记录） |
| `tools/` | 测试与诊断脚本 |

## 启动

```bat
:: 后端（默认 http://127.0.0.1:8765）
env\python.exe -m uvicorn solver.app.main:app --host 127.0.0.1 --port 8765

:: 前端（开发模式，http://127.0.0.1:5173）
cd frontend && npm install && npm run dev
```

## 功能

### 元件库（17 种）
- **电源**：电压源、**交流电压源**、电流源、**交流电流源**、**三相电源**、接地
- **无源/动态**：电阻、**电容**、**电感**、**开关**
- **受控源/磁路**：压控电压源 μ、压控电流源 gm、流控电压源 r、流控电流源 β、**理想变压器 n**
- **电子技术**：**二极管**、**稳压管**、**三极管**、**集成运放**

### 分析域（左侧「分析域」）
| 域 | 说明 |
|---|---|
| 直流 | 电容开路、电感短路；二极管/稳压管/三极管用通断+模型迭代 |
| 正弦交流（相量） | 复数 MNA，结果给 **有效值 ∠ 相角**；可画**相量图**、**扫频** |
| 暂态（时域） | 梯形法积分，出 **波形**；支持初值 `v0/i0`、**开关中途换路** |

### 右栏折叠栏
`元件属性` / `代数参考值` / **`相量图`** / **`曲线(波形·扫频)`** / **`解法步骤`** / `符号公式` / `节点探针` / `校验`

### 手算算法（自动判断该用哪个，「解法步骤」栏里给过程）
- **端口等效（戴维南）**：元件值没给也能反解出来（例：`电工与电子2.7` 的 R5 = 2Ω）
- **节点电压法**：逐节点 KCL + 代入数值
- **叠加定理**：每个独立源单独作用后相加
- **最大功率传输**：`R = Rth`、`Pmax = Voc²/(4Rth)`
- **三要素法**：f(0⁺)、f(∞)、τ（τ 用端口等效电阻算）
- **串并联化简**：识别串/并联并给等效值
- **三极管微变等效**：Q 点 → `rbe`、`gm` → π 模型 → `Au`
- **三相**：线电压 = √3×相电压（超前 30°）、两表法功率、Y/Δ 换算

### 符号公式（lcapy）
支持 R/C/L/V/I/E/G/H/F/变压器/交流源/阶跃源，出 LaTeX；非线性器件（二极管等）自动跳过。

## 关键约定
- 支路电流参考方向：**p0 → p1**；画布箭头画的是**实际方向**
- 电压源 **p0 是正端**；电流源箭头指向 p0
- 元件引脚名与后端 `solver/app/devices.py` **一一对应**（前端 `core/geometry.js` 必须同步）

## 已知限制
- 开关只能「静态」或「某个时刻翻转一次」（`t_switch`），不能多次翻转
- 二阶以上暂态用数值解，不自动给三要素法（只对一阶电路给）
- 理想变压器在符号通道给的是 `cos(ωt)` 形式（数值正确，不是相量形式）
- 数字电路（门/真值表/卡诺图/触发器）**未实现**
